# 💜 약속잡기

친구들마다 따로 약속을 만들고, 날짜와 장소를 한 번에 정하는 웹앱입니다.

## 기능

- **새 약속** · 방장이 약속 이름, 아이콘, 약속 잡을 달(여러 개 선택, 예: 3월·4월), **모일 인원**을 고르고 **참여코드 + 비밀번호**를 정해요
- **참여하기** · 친구들은 참여코드와 비밀번호를 입력하고 이름을 적으면 들어와요 (로그인 없음, 약속마다 멤버가 달라요)
- **안 되는 날 표시** · 날짜를 누르면 `종일 / 오전 / 오후 안 돼요`를 고르고, `18시까지 안 돼요`, `15시부터 안 돼요` 같은 시간과 메모를 남길 수 있어요
- **입력 완료 → 가능한 날 공개** · 정한 인원이 모두 입력 완료를 누르면 `하루 종일 / 오전만 / 오후만` 모두 되는 날을 보여줘요 (미리 보기도 가능)
- **장소 정하기** · 각자 지역을 입력하고 추천 1~3위를 받아요
  - 🧭 **중간 지역** · 모두의 평균 이동거리와 최장 이동거리가 짧은 도시
  - 🎲 **우리 동네** · 멤버들 지역 중 랜덤
  - 🌏 **완전 랜덤** · 전국 여행지 중 랜덤

빌드 과정이 없는 정적 사이트(HTML·CSS·JS)입니다.

## 로컬에서 실행

```bash
python3 -m http.server 8000   # http://localhost:8000
```

`config.js`가 비어 있으면 **체험 모드**예요. 데이터가 이 브라우저에만 저장돼요.

## 친구들과 쓰기 (Supabase, 무료)

1. [supabase.com](https://supabase.com)에서 새 프로젝트 생성
2. **SQL Editor**에서 [`supabase/schema.sql`](supabase/schema.sql) 실행
3. **Project Settings → API**의 `Project URL`, `anon public` 키를 `config.js`에 입력
4. GitHub Pages / Netlify / Vercel 중 하나로 배포 (빌드 명령 없음)

> 테이블은 직접 접근할 수 없고, 비밀번호를 서버에서 확인하는 함수로만 읽고 쓸 수 있어요. 비밀번호는 암호화(bcrypt)해서 저장해요.
> 단, 같은 약속 안에서는 이름만으로 구분하니 친구끼리 쓰는 용도로 생각해 주세요.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점 |
| `app.js` | 화면(홈·새 약속·참여·일정·결과·장소) |
| `store.js` | 저장소 (Supabase 함수 또는 체험 모드 localStorage) |
| `data.js` | 지역 좌표·여행지, 공휴일 |
| `config.js` | Supabase 연결 정보 |
| `supabase/schema.sql` | 테이블과 비밀번호 확인 함수 |
